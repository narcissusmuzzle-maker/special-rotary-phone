U613 «Таймер» для Amazfit Bip Max — версия 5 (приложение 1.1.1).

КАК УСТАНОВИТЬ (так же, как раньше)
1. В вашем репозитории на GitHub удалите старые файлы часового приложения и загрузите ВСЁ из этой папки в корень.
   Скрытых папок в архиве нет. Файл build.yml лежит в корне; сборку на GitHub запускает файл из .github/workflows —
   он у вас уже есть с прошлых версий (build-watch.yml) и не менялся, ничего делать не нужно.
   Если репозиторий новый: Add file -> Create new file, имя  .github/workflows/build.yml , внутрь вставить текст из build.yml.
2. Settings -> Pages -> ветка gh-pages (если ещё не включено). Вкладка Actions: дождаться зелёной галочки.
3. Releases -> QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Приложение на телефоне — то же (LuvU613 5.8), менять не нужно. Zepp и LuvU613: батарея «Без ограничений».

ЧТО ИЗМЕНИЛОСЬ В ВЕРСИИ 5
- Добавлено разрешение device:os.local_storage: из-за его отсутствия на экране была надпись DENIED, а таймеры не сохранялись
  (при перезапуске приложения будильником состояние терялось и вибрации не было).
- В тестовом режиме под красной кнопкой мелкая серая строка диагностики: статус будильника, сколько раз приложение
  запускалось будильником, работает ли память.

ЧТО БЫЛО В ВЕРСИИ 4
- Шесть занятий (два ряда): 🤿 🎨 🩸 / 📖 🧬 💀, под ними красный таймер на 15 минут.
- Эмодзи на чёрном фоне, без плашек. Когда таймер включён — эмодзи полностью заменяется цифрами.
- Включили другой таймер — прежний снова становится эмодзи, но помнит свой остаток.
  Нажатие на идущий таймер — пауза (жёлтые цифры остаются).
- Пока идёт таймер, выйти из приложения нельзя (свайпы и кнопки блокируются). Пауза нажатием — и можно выходить.
- Тестовый режим (долгое нажатие на красный): час = 10 секунд, красный = 15 секунд, часы ЗАСЧИТЫВАЮТСЯ в трекере.
  Тест переживает перезапуск приложения, чтобы можно было проверить пробуждение при погасшем экране.
- В app.json добавлено разрешение device:os.alarm — без него будильник пробуждения не ставился.
- Поля экрана: в page/index.js вверху константы LEFT, TOP, BOTTOM — их можно крутить, если что-то ещё обрезано.
